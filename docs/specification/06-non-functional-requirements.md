# Нефункциональные требования

## 1. Производительность

### 1.1 Загрузка приложения

**NFR-PERF-01.** Время первоначальной загрузки приложения при использовании ноутбука не должно превышать 5 секунд.

**NFR-PERF-02.** Время первоначальной загрузки приложения при использовании смартфона не должно превышать 7 секунд.

**NFR-PERF-03.** При повторном открытии приложения на том же устройстве время загрузки 
не должно превышать 3 секунд для ноутбука и 4 секунд для смартфона.

**NFR-PERF-04.** После загрузки приложения пользователь должен иметь возможность сразу взаимодействовать с интерфейсом, а именно:
выбирать категории запросов, открывать доступные сценарии и вводить сообщения.


### 1.2 Выполнение пользовательских запросов

**NFR-PERF-05.** Время выполнения стандартных аналитических запросов не должно превышать 10 секунд.

**NFR-PERF-06.** Время выполнения сложных аналитических запросов,
предполагающих обработку и агрегацию большого объема данных, не должно превышать 20 секунд.

**NFR-PERF-07.** Время выполнения запросов, предполагающих обработку данных за продолжительные периоды, 
не должно превышать 30 секунд.

**NFR-PERF-08.** Время выполнения запроса должно учитывать полный цикл его обработки, а именно:
получение необходимых данных из iiko, обработку данных и подготовку результата к отображению пользователю.

### 1.3 Отображение пользователю

**NFS-PERF-09.** После завершения обработки запроса результат должен отображаться 
в диалоговом интерфейсе не позднее чем через 1 секунду.

**NFS-PERF-10.** Отображение текстовых ответов, числовых показателей, 
списков и таблиц не должно сопровождаться заметными задержками или зависаниями интерфейса.

**NFS-PERF-11.** При выполнении запроса продолжительностью более 5 секунд 
система должна отображать пользователю уведомление о процессе обработки запроса.

**NFS-PERF-12.** Во время выполнения запроса интерфейс должен оставаться доступным 
для просмотра истории диалога и навигации по приложению.

### 1.4 Общие требования к производительности

**NFS-PERF-13.** Указанные требования к производительности должны соблюдаться 
при использовании актуальных версий поддерживаемых браузеров на устройствах с характеристиками,
достаточными для комфортной работы с современными веб-приложениями.

**NFS-PERF-14.** Требования к времени загрузки и выполнения запросов должны соблюдаться 
при стабильном интернет-соединении со скоростью не менее 10 Мбит/с.

**NFS-PERF-15.** Производительность приложения не должна существенно различаться 
в зависимости от используемого устройства, за исключением допустимых различий во времени первоначальной загрузки.
