# Нефункциональные требования

## 1. Производительность

### 1.1 Загрузка приложения

**NFR-PERF-01.** Время первоначальной загрузки приложения при использовании ноутбука не должно превышать 5 секунд.

**NFR-PERF-02.** Время первоначальной загрузки приложения при использовании смартфона не должно превышать 7 секунд.

**NFR-PERF-03.** При повторном открытии приложения на том же устройстве время загрузки 
не должно превышать 3 секунд для ноутбука и 4 секунд для смартфона.

**NFR-PERF-04.** После загрузки приложения пользователь должен иметь возможность сразу взаимодействовать с интерфейсом, а именно:
выбирать категории запросов, открывать доступные сценарии и вводить сообщения.


### 1.2 Выполнение пользовательских запросов

**NFR-PERF-05.** Время выполнения стандартных аналитических запросов не должно превышать 10 секунд.

**NFR-PERF-06.** Время выполнения сложных аналитических запросов,
предполагающих обработку и агрегацию большого объема данных, не должно превышать 20 секунд.

**NFR-PERF-07.** Время выполнения запросов, предполагающих обработку данных за продолжительные периоды, 
не должно превышать 30 секунд.

**NFR-PERF-08.** Время выполнения запроса должно учитывать полный цикл его обработки, а именно:
получение необходимых данных из iiko, обработку данных и подготовку результата к отображению пользователю.

### 1.3 Отображение пользователю

**NFS-PERF-09.** После завершения обработки запроса результат должен отображаться 
в диалоговом интерфейсе не позднее чем через 1 секунду.

**NFS-PERF-10.** Отображение текстовых ответов, числовых показателей, 
списков и таблиц не должно сопровождаться заметными задержками или зависаниями интерфейса.

**NFS-PERF-11.** При выполнении запроса продолжительностью более 5 секунд 
система должна отображать пользователю уведомление о процессе обработки запроса.

**NFS-PERF-12.** Во время выполнения запроса интерфейс должен оставаться доступным 
для просмотра истории диалога и навигации по приложению.

### 1.4 Общие требования к производительности

**NFS-PERF-13.** Указанные требования к производительности должны соблюдаться 
при использовании актуальных версий поддерживаемых браузеров на устройствах с характеристиками,
достаточными для комфортной работы с современными веб-приложениями.

**NFS-PERF-14.** Требования к времени загрузки и выполнения запросов должны соблюдаться 
при стабильном интернет-соединении со скоростью не менее 10 Мбит/с.

**NFS-PERF-15.** Производительность приложения не должна существенно различаться 
в зависимости от используемого устройства, за исключением допустимых различий во времени первоначальной загрузки.

## 2. Доступность и надежность

### 2.1 Доступность приложения

**NFR-AVAIL-01.** Доступность приложения должна составлять не менее 99,5% времени в течение календарного месяца.

**NFR-AVAIL-02.** Приложение должно быть доступно для использования круглосуточно, 
за исключением периодов планового технического обслуживания.

**NFR-AVAIL-03.** О плановых технических работах, приводящих к недоступности приложения, 
пользователь должен быть уведомлен не менее чем за 24 часа.

**NFR-AVAIL-04.** В случае возникновения критического сбоя, 
приводящего к полной недоступности приложения, работоспособность системы должна быть восстановлена 
в течение 48 часов с момента обнаружения проблемы.

### 2.2 Устойчивость к сбоям и ошибкам

**NFR-AVAIL-05.** Возникновение ошибки при выполнении отдельного пользовательского запроса
не должно приводить к полной недоступности приложения.

**NFR-AVAIL-06.** При возникновении ошибки получения или обработки данных 
система должна отображать понятное пользователю уведомление о невозможности выполнения запроса.

**NFR-AVAIL-07.** Технические ошибки не должны приводить к потере ранее полученных 
и отображенных в истории диалога результатов.

**NFR-AVAIL-08.** При временной недоступности внешней системы iiko
приложение должно сохранять возможность просмотра ранее загруженной истории диалога.

**NFR-AVAIL-09.** При восстановлении соединения с внешней системой
пользователь должен иметь возможность повторно выполнить ранее неудавшийся запрос.

### 2.3 Работа с внешней системой iiko

**NFR-AVAIL-10.** Система должна проверять доступность подключения к iiko
и отображать текущее состояние подключения в интерфейсе приложения.

**NFR-AVAIL-11.** При потере соединения с iiko система должна информировать пользователя
о невозможности получения актуальных данных.

**NFR-AVAIL-12.** При временных ошибках взаимодействия с API iiko 
система должна предусматривать автоматические повторные попытки выполнения запроса; не более 2 дополнительных попыток.

**NFR-AVAIL-13.** Если повторные попытки выполнения запроса не привели к успешному результату,
система должна прекратить выполнение операции и уведомить пользователя об ошибке.

**NFR-AVAIL-14.** Недоступность API iiko не должна приводить 
к потере работоспособности остальных компонентов приложения, не зависящих от получения новых данных из iiko.

### 2.4 Сохранность состояния приложения

**NFR-AVAIL-15.** При обновлении страницы или повторном открытии приложения ранее сохраненная история диалога
должна оставаться доступной пользователю.

**NFR-AVAIL-16.** При временной потере интернет-соединения система должна корректно обрабатывать незавершенные операции
и уведомлять пользователя о необходимости.

**NFR-AVAIL-17.** Сбой при выполнении одного запроса не должен нарушать возможность выполнения последующих запросов
после восстановления работоспособности системы.

**NFR-AVAIL-18.** Повторная отправка запроса после технической ошибки не должна приводить 
к некорректному дублированию результатов или сообщений в истории диалога.

### 2.5 Восстановление после сбоев

**NFR-AVAIL-19.** После восстановления работоспособности сервера 
пользователь должен иметь возможность продолжить работу с приложением
без необходимости повторной настройки подключения к iiko.

**NFR-AVAIL-20.** После перезапуска приложения должны сохраняться ранее записанные данные и история диалога.

**NFR-AVAIL-21.** Восстановление работоспособности приложения не должно приводить
к искажению или потере ранее сохраненных данных.


Указанные требования к доступности приложения относятся к самому iikoAssistant 
и не распространяются на доступность внешней системы iiko,
интернет-соединения пользователя и других сторонних сервисов.
