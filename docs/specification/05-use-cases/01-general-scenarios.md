# Общие сценарии

## UC-01. Получение информации с помощью панели категорий

| Поле        | Описание                                                     |
| ----------- | ------------------------------------------------------------ |
| Инициатор   | Владелец заведения                                           |
| Цель        | Получить информацию о деятельности заведения                 |
| Предусловия | Пользователь открыл приложение. Подключение к iiko настроено |
| Триггер     | Пользователь выбирает категорию запросов                     |
| Итерация    | 1                                                            |

### Основной сценарий

| №   | Действие пользователя          | Действие системы                                            |
| --- | ------------------------------ | ----------------------------------------------------------- |
| 1   | Открывает приложение           | Отображает основную страницу                                |
| 2   | Выбирает категорию             | Отображает доступные запросы выбранной категории            |
| 3   | Выбирает необходимый запрос    | Отображает доступные параметры запроса                      |
| 4   | Выбирает необходимые параметры | Формирует запрос на основе выбранных параметров             |
| 5   | -                              | Добавляет запрос в историю диалога                          |
| 6   | -                              | Выполняет соответствующий сценарий получения данных из iiko |
| 7   | -                              | Обрабатывает полученные данные                              |
| 8   | -                              | Отображает результат в области диалога                      |

### Альтернативные сценарии

- A1. Пользователь возвращается к предыдущему шагу. Система отображает предыдущий уровень навигации
- A2. Для выполнения запроса недостаточно параметров. Система запрашивает недостающую информацию
- A3. При получении данных возникает ошибка. Система отображает уведомление о невозможности выполнения запроса

### Постусловия

Результат запроса отображен в истории диалога либо пользователю сообщено о невозможности выполнения запроса.

## UC-02. Получение информации с помощью текстового запроса

| Поле        | Описание                                                     |
| ----------- | ------------------------------------------------------------ |
| Инициатор   | Владелец заведения                                           |
| Цель        | Получить информацию посредством ввода текстового запроса     |
| Предусловия | Пользователь открыл приложение. Подключение к iiko настроено |
| Триггер     | Пользователь вводит сообщение в поле ввода                   |
| Итерация    | 1                                                            |

### Основной сценарий

| №   | Действие пользователя              | Действие системы                                        |
| --- | ---------------------------------- | ------------------------------------------------------- |
| 1   | Открывает приложение               | Отображает основную страницу                            |
| 2   | Вводит текстовый запрос            | Ожидает отправки сообщения                              |
| 3   | Нажимает Enter или кнопку отправки | Получает текст сообщения                                |
| 4   | -                                  | Проверяет соответствие запроса поддерживаемым сценариям |
| 5   | -                                  | Определяет соответствующий сценарий                     |
| 6   | -                                  | Запрашивает недостающие параметры, если они необходимы  |
| 7   | -                                  | Выполняет запрос к iiko                                 |
| 8   | -                                  | Отображает результат в области диалога                  |

### Альтернативные сценарии

- A1. Запрос не соответствует поддерживаемым сценариям. Система сообщает о невозможности обработки
и предлагает воспользоваться панелью категорий
- A2. Запрос содержит недостаточно информации. Система запрашивает недостающие параметры
- A3. Возникает ошибка при получении данных. Система отображает соответствующее уведомление

### Постусловия

Пользователь получил ответ на запрос либо уведомление о невозможности его выполнения.
