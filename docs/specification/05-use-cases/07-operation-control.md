# Контроль операций и потерь

## UC-35. Число отмен за период

| Поле        | Описание                                                                                                 |
|-------------|----------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                       |
| Цель        | Получить информацию о количестве отмененных заказов за выбранный период времени                          |
| Предусловия | Доступно подключение к iiko. В системе имеются данные об операциях с заказами, включая отмененные заказы |
| Триггер     | Пользователь выбирает запрос "Число отмен за период"                                                     |
| Итерация    | 2                                                                                                        |

### Основной сценарий

| № | Действие пользователя                           | Действие системы                                                                 |
|---|-------------------------------------------------|----------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Контроль операций и потерь" | Отображает доступные запросы                                                     |
| 2 | Выбирает "Число отмен за период"                | Отображает варианты выбора периода                                               |
| 3 | Выбирает период                                 | Формирует запрос с указанным периодом                                            |
| 4 | -                                               | Получает из iiko данные об отмененных заказах за выбранный период                |
| 5 | -                                               | Определяет общее количество отмен за выбранный период                            |
| 6 | -                                               | Группирует отмены по датам                                                       |
| 7 | -                                               | Рассчитывает количество отмен за каждый день выбранного периода                  |
| 8 | -                                               | Отображает общее количество отмен и их распределение по дням за выбранный период |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. За выбранный период отсутствуют отмененные заказы. Система сообщает об отсутствии отмен
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке
- A4. За выбранный период обнаружены отмены без указания причины. 
Система учитывает такие отмены в общем количестве, отдельно отмечая отсутствие причины
- A5. Один заказ отменялся несколько раз или повторно проводился через систему.
Система действует согласно глоссарию: "Дата отнесения операции", "Отмена заказа"

### Постусловия

В истории диалога отображено общее количество отмен за выбранный период с разбивкой по дням.

## UC-38. Контроль списаний за период

| Поле        | Описание                                                                                                                            |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                                                  |
| Цель        | Определить сотрудников, которые чаще всего проводят операции списания за выбранный период времени                                   |
| Предусловия | Доступно подключение к iiko. В системе имеются данные об операциях списания, их датах, причинах и сотрудниках, выполнивших списания |
| Триггер     | Пользователь выбирает запрос "Контроль списаний за период"                                                                          |
| Итерация    | 2                                                                                                                                   |

### Основной сценарий

| № | Действие пользователя                           | Действие системы                                                                                                                    |
|---|-------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Контроль операций и потерь" | Отображает доступные запросы                                                                                                        |
| 2 | Выбирает "Контроль списаний за период"          | Отображает варианты выбора периода                                                                                                  |
| 3 | Выбирает период                                 | Формирует запрос с указанным периодом                                                                                               |
| 4 | -                                               | Получает из iiko данные об операциях списания за выбранный период, включая даты, суммы и сотрудников, выполнивших списания          |
| 5 | -                                               | Группирует операции списания по сотрудникам                                                                                         |
| 6 | -                                               | Рассчитывает общее количество списаний, выполненных каждым сотрудником                                                              |
| 7 | -                                               | Сортирует сотрудников по количеству проведенных списаний в порядке убывания                                                         |
| 8 | -                                               | Отображает рейтинг сотрудников с указанием количества проведенных списаний за выбранный период и выделяет лидеров по числу операций |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. За выбранный период списания не проводились. Система сообщает об отсутствии операций списания
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке
- A4. У некоторых операций отсутствует информация о сотруднике, выполнившем списание.
Система учитывает такие операции отдельно в категории "Сотрудник не указан"
- A5. Несколько сотрудников провели одинаковое количество списаний. Система действует согласно глоссарию "Экстремум"
- A6. Один сотрудник провел списания по нескольким причинам.
Система отображает общее количество списаний сотрудника без дублирования операций

### Постусловия

В истории диалога отображен рейтинг сотрудников по количеству проведенных операций списания 
за выбранный период с указанием количества списаний каждого сотрудника 
и сотрудников с наибольшей частотой проведения таких операций.
