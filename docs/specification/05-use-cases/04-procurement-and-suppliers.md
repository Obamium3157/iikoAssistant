# Закупки и поставщики

## UC-19. История закупок

| Поле        | Описание                                                                                                                |
|-------------|-------------------------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                                      |
| Цель        | Получить информацию о количестве и стоимости закупленных товаров у выбранного поставщика за определенный период времени |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о закупках и поставщиках                                          |
| Триггер     | Пользователь выбирает запрос "История закупок"                                                                          |
| Итерация    | 1                                                                                                                       |

### Основной сценарий

| № | Действие пользователя                     | Действие системы                                                                     |
|---|-------------------------------------------|--------------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Закупки и поставщики" | Отображает доступные запросы                                                         |
| 2 | Выбирает "История закупок"                | Отображает список поставщиков                                                        |
| 3 | Выбирает поставщика                       | Отображает варианты выбора периода                                                   |
| 4 | Выбирает период                           | Формирует запрос с указанным поставщиком и периодом                                  |
| 5 | -                                         | Получает данные о закупках из iiko                                                   |
| 6 | -                                         | Группирует закупки по выбранному поставщику                                          |
| 7 | -                                         | Рассчитывает общее количество закупленных товаров и их стоимость за период           |
| 8 | -                                         | Отображает результаты с указанием товаров, количества, общей суммы и периода закупок |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. За выбранный период отсутствуют данные о закупках у поставщика. Система сообщает об отсутствии данных
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

### Постусловия

В истории диалога отображена информация о закупках у выбранного поставщика за указанный период 
с указанием наименований товаров, закупленных количеств и общей стоимости закупок.
