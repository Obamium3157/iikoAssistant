# Продажи и выручка

## UC-03. Выручка за период

| Поле        | Описание                                                         |
|-------------|------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                               |
| Цель        | Получить информацию о выручке за выбранный период времени        |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о продажах |
| Триггер     | Пользователь выбирает запрос "Выручка за период"                 |
| Итерация    | 1                                                                |

### Основной сценарий

| № | Действие пользователя                  | Действие системы                                   |
|---|----------------------------------------|----------------------------------------------------|
| 1 | Выбирает категорию "Продажи и выручка" | Отображает доступные запросы                       |
| 2 | Выбирает "Выручка за период"           | Отображает варианты выбора периода                 |
| 3 | Выбирает период                        | Формирует запрос с указанным периодом              |
| 4 | -                                      | Получает данные о продажах из iiko                 |
| 5 | -                                      | Рассчитывает суммарную выручку за выбранный период |
| 6 | -                                      | Отображает результат и период расчета              |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. За выбранный период отсутствуют данные. Система сообщает об отсутствии данных
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

### Постусловия

В истории диалога отображена выручка за выбранный период

| Инициатор   | Владелец заведения                                               |
| Цель        | Сравнить выручку за два периода времени                          |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о продажах |
| Триггер     | Пользователь выбирает запрос "Динамика выручки"                  |
| Итерация    | 2                                                                |

### Основной сценарий

| № | Действие пользователя                  | Действие системы                                                                      |
|---|----------------------------------------|---------------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Продажи и выручка" | Отображает доступные запросы                                                          |
| 2 | Выбирает "Динамика выручки"            | Запрашивает первый период                                                             |
| 3 | Выбирает первый период                 | Запрашивает второй период                                                             |
| 4 | Выбирает второй период                 | Формирует запрос с указанными периодами                                               |
| 5 | -                                      | Получает данные о продажах из iiko                                                    |

| 7 | -                                      | Отображает выручку за оба периода вместе с абсолютной разницей и разницей в процентах |

### Альтернативные сценарии

- A1. Пользователь ввел некорректный период. Система предлагает либо ввести период еще раз
- A2. За один из выбранных периодов отсутствуют данные. Система сообщает об отсутствии данных
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

### Постусловия

В истории чата отображены периоды времени, выручка за них, а также абсолютная и процентная разница между ними.
