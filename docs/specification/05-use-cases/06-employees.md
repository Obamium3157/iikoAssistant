# Персонал и эффективность работы

## UC-30. Наибольшая выручка за период

| Поле        | Описание                                                                                                          |
|-------------|-------------------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                                |
| Цель        | Определить сотрудника выбранной должности, который принес наибольшую выручку за выбранный период времени          |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о продажах, выручке и сотрудниках с указанием их должностей |
| Триггер     | Пользователь выбирает запрос "Наибольшая выручка за период"                                                       |
| Итерация    | 1                                                                                                                 |

### Основной сценарий

| № | Действие пользователя                                | Действие системы                                                                |
|---|------------------------------------------------------|---------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Персонал и эффективность работы" | Отображает доступные запросы                                                    |
| 2 | Выбирает "Наибольшая выручка за период"              | Запрашивает должность сотрудника                                                |
| 3 | Указывает должность                                  | Отображает варианты выбора периода                                              |
| 4 | Выбирает период                                      | Формирует запрос с указанной должностью и периодом                              |
| 5 | -                                                    | Получает данные о продажах, выручке и сотрудниках из iiko                       |
| 6 | -                                                    | Группирует выручку по сотрудникам указанной должности                           |
| 7 | -                                                    | Сортирует сотрудников по сумме выручки в порядке убывания                       |
| 8 | -                                                    | Отображает сотрудника с наибольшей выручкой, сумму его выручки и период расчета |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. За выбранный период отсутствуют данные о продажах сотрудников указанной должности.
Система сообщает об отсутствии данных
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

### Постусловия

В истории диалога отображена информация о сотруднике указанной должности, 
который принес наибольшую выручку за выбранный период, с указанием его имени и суммы выручки.

### Основной сценарий

| № | Действие пользователя                                | Действие системы                                                                                        |

| 2 | Выбирает "Количество обслуженных заказов за период"  | Отображает варианты выбора периода                                                                      |
| 3 | Выбирает период                                      | Формирует запрос с указанным периодом                                                                   |

| 7 | -                                                    | Определяет сотрудника, обслужившего наибольшее количество заказов                                       |
| 8 | -                                                    | Отображает список сотрудников с количеством обслуженных заказов и выделяет лидера по количеству заказов |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. За выбранный период отсутствуют данные о заказах. Система сообщает об отсутствии данных

- A5. Заказ обслуживался несколькими сотрудниками.
Система действует согласно глоссарию "Обслуженный заказ"

### Постусловия

В истории диалога отображен рейтинг сотрудников по количеству обслуженных заказов за выбранный период с указанием количества заказов каждого сотрудника и сотрудника с наибольшим результатом.

| Поле        | Описание                                                                                                                                   |
|-------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                                                         |

| № | Действие пользователя                                | Действие системы                                                                              |
|---|------------------------------------------------------|-----------------------------------------------------------------------------------------------|

| 2 | Выбирает "Анализ рабочих часов"                      | Отображает варианты выбора периода                                                            |
| 3 | Выбирает период                                      | Формирует запрос с указанным периодом                                                         |

| 8 | -                                                    | Отображает список сотрудников с количеством отработанных часов за выбранный период            |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. За выбранный период отсутствуют данные о рабочих сменах. Система сообщает об отсутствии данных
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

Система отображает сотрудников с одинаковым результатом на одном уровне рейтинга

### Постусловия

В истории диалога отображен список сотрудников с указанием количества отработанных часов за выбранный период, отсортированный по убыванию продолжительности рабочего времени.

## UC-34. Анализ динамики количества обслуженных заказов сотрудника

| Поле        | Описание                                                                                                                                                                 |
|-------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                                                                                       |
| Цель        | Оценить изменение количества обслуженных заказов конкретного сотрудника за выбранный период путем сравнения количества заказов в первый и последний рабочий день периода |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о сотрудниках, их должностях и заказах, обслуженных ими за выбранный период                                        |
| Триггер     | Пользователь выбирает запрос "Анализ динамики количества заказов сотрудника"                                                                                             |
| Итерация    | 2                                                                                                                                                                        |

### Основной сценарий

| № | Действие пользователя                                    | Действие системы                                                                                                                                                     |
|---|----------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Персонал и эффективность работы"     | Отображает доступные запросы                                                                                                                                         |
| 2 | Выбирает "Анализ динамики количества заказов сотрудника" | Предлагает выбрать должность сотрудника                                                                                                                              |
| 3 | Выбирает должность                                       | Отображает список сотрудников, работающих на выбранной должности                                                                                                     |
| 4 | Выбирает конкретного сотрудника                          | Предлагает выбрать период анализа                                                                                                                                    |
| 5 | Выбирает период времени                                  | Формирует запрос с указанным сотрудником и периодом                                                                                                                  |
| 6 | -                                                        | Получает из iiko данные о заказах, обслуженных выбранным сотрудником за указанный период                                                                             |
| 7 | -                                                        | Определяет количество обслуженных заказов в первый и последний рабочий день периода, рассчитывает абсолютное и процентное изменение                                  |
| 8 | -                                                        | Отображает результаты сравнения с указанием количества заказов в первый и последний рабочий день, абсолютного и процентного изменения, а также направления изменения |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. На выбранной должности отсутствуют сотрудники. Система сообщает об отсутствии сотрудников по указанной должности
- A3. За выбранный период отсутствуют данные о заказах сотрудника. Система сообщает об отсутствии данных
- A4. Не удалось получить данные из iiko. Система отображает сообщение об ошибке
- A5. В течение выбранного периода сотрудник сменил должность. Система уточняет, 
учитывать ли заказы только за время работы на должности X или за весь выбранный период
- A6. Для одного из сравниваемых дней отсутствуют данные.
Система сообщает о невозможности корректного сравнения и указывает, за какой именно день данные отсутствуют
- A7. Один заказ обслуживался несколькими сотрудниками. 
Система действует согласно глоссарию "Обслуженный заказ"
- A8. Количество заказов в первый рабочий день равно нулю. Система отображает абсолютное изменение без процентного и поясняет, что процентное изменение не определено

### Постусловия

В истории диалога отображены результаты анализа динамики количества обслуженных заказов выбранного сотрудника 
за указанный период с указанием количества заказов в первый и последний рабочий день, абсолютного и процентного изменения.

_Примечание: см. глоссарий "Первый рабочий день периода", "Последний рабочий день периода",
"Изменение показателя"._
