## UC-29. Выявление позиций с низкой рентабельностью

| Поле        | Описание                                                                                                                                                                                                                                 |
|-------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                                                                                                                                                       |
| Цель        | Выявить позиции меню, рентабельность которых ниже заданного порога за выбранный период                                                                                                                                                   |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о продажах по позициям меню, фактических ценах продаж, составе блюд и закупочных ценах ингредиентов. Значение порога рентабельности запрашивается у пользователя в рамках сценария |
| Триггер     | Пользователь выбирает запрос "Позиции с низкой рентабельностью"                                                                                                                                                                          |
| Итерация    | 2                                                                                                                                                                                                                                        |

### Основной сценарий

| №  | Действие пользователя                             | Действие системы                                                                                                     |
|----|---------------------------------------------------|----------------------------------------------------------------------------------------------------------------------|
| 1  | Выбирает категорию "Анализ меню и рентабельности" | Отображает доступные запросы                                                                                         |
| 2  | Выбирает "Позиции с низкой рентабельностью"       | Запрашивает период анализа                                                                                           |
| 3  | Выбирает период                                   | Запрашивает порог рентабельности и предлагает значение по умолчанию                                                  |
| 4  | Подтверждает или изменяет порог                   | Запрашивает минимальное количество продаж для фильтра и предлагает значение по умолчанию                             |
| 5  | Подтверждает или изменяет фильтр                  | Формирует запрос с периодом, порогом и фильтром                                                                      |
| 6  | -                                                 | Получает из iiko данные о продажах позиций с учетом скидок и возвратов, составе блюд и закупочных ценах ингредиентов |
| 7  | -                                                 | Рассчитывает фактическую цену продажи и себестоимость каждой позиции за период                                       |
| 8  | -                                                 | Рассчитывает рентабельность каждой позиции и отбирает позиции со значением ниже порога                               |
| 9  | -                                                 | Исключает из выборки позиции, количество продаж которых меньше заданного фильтра                                     |
| 10 | -                                                 | Сортирует позиции по возрастанию рентабельности, а при равном значении — по убыванию выручки                         |
| 11 | -                                                 | Отображает список позиций с выручкой, себестоимостью, маржой, рентабельностью и количеством продаж                   |
| 12 | -                                                 | Отображает период, примененный порог, фильтр и предупреждение о позициях с неполными данными                         |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. Пользователь не изменяет порог. Система использует значение по умолчанию и явно указывает его в ответе
- A3. Для части позиций отсутствует техкарта или закупочная цена ингредиентов. Система не включает такие позиции в рейтинг и отдельно сообщает их количество
- A4. Для дат продаж отсутствует история закупочных цен. Система действует согласно глоссарию "Себестоимость позиции за период", "Неполные данные"
- A5. Позиция продавалась со скидкой. Система использует фактическую цену продажи после скидки; сумма скидки показывается отдельной колонкой
- A6. Позиций с рентабельностью ниже порога не найдено. Система сообщает, что все позиции с полными данными превышают порог
- A7. Не удалось получить данные из iiko. Система отображает понятное пользователю сообщение без технических подробностей

### Постусловия

В истории диалога отображен список позиций с рентабельностью ниже порога за выбранный период
с указанием выручки, себестоимости, маржи, рентабельности и количества продаж. Если такие позиции
не найдены либо данные неполны, пользователю отображается соответствующее сообщение.
