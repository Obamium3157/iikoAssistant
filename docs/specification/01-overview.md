# Общая информация о проекте

## Название и назначение

*iikoAssistant* - программа для оптимизации работы с iiko.
Она позволяет быстрее и удобнее получать информацию из системы о продажах, складских данных,
закупках и поставщиках, а также о производительности сотрудников. Помимо этого,
программа позволяет анализировать меню, выявляя, к примеру, популярные и непопулярные позиции.
На основе этой информации iikoAssistant может составлять отчеты.

## Проблема, которую решает система

Владельцу заведения необходимо регулярно отслеживать ключевые показатели бизнеса, 
однако взаимодействие с iiko требует выполнения множества действий и навигации по различным разделам системы.
Вместо быстрого получения ответов на конкретные вопросы 
владелец вынужден самостоятельно искать, фильтровать и интерпретировать данные.

## Целевая аудитория

Приложение предназначено исключительно для владельца заведения, использующего iiko
для управления бизнесом.

## Цели проекта

- Сократить время на получение бизнес-аналитики до нескольких минут
- Предоставить владельцу единую точку доступа ко всем ключевым показателям бизнеса
- Автоматизировать рутинные операции по сбору и агрегации данных из iiko
- Выявлять проблемные зоны в бизнесе (низкая рентабельность, критические остатки)
