# Фонд оплаты труда

## UC-36. Фонд оплаты труда за период

| Поле        | Описание                                                                                                                                       |
|-------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                                                             |
| Цель        | Получить информацию об общей сумме ФОТ за выбранный период времени                                                                             |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о сотрудниках, отработанном времени, ставках оплаты труда и начислениях заработной платы |
| Триггер     | Пользователь выбирает запрос "ФОТ за период"                                                                                                   |
| Итерация    | 1                                                                                                                                              |

### Основной сценарий

| № | Действие пользователя                  | Действие системы                                                                                               |
|---|----------------------------------------|----------------------------------------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Фонд оплаты труда" | Отображает доступные запросы                                                                                   |
| 2 | Выбирает "ФОТ за период"               | Предлагает выбрать период расчета: неделю или месяц                                                            |
| 3 | Выбирает неделю или месяц              | Формирует запрос с указанным периодом                                                                          |
| 4 | -                                      | Получает из iiko данные о сотрудниках, отработанном времени и начислениях заработной платы за выбранный период |
| 5 | -                                      | Рассчитывает общую сумму фонда оплаты труда за выбранный период                                                |
| 6 | -                                      | Группирует расходы на оплату труда по сотрудникам                                                              |
| 7 | -                                      | Рассчитывает долю каждого сотрудника в общем фонде оплаты труда                                                |
| 8 | -                                      | Отображает общую сумму ФОТ за выбранный период и разбивку расходов по сотрудникам                              |

### Альтернативные сценарии

- A1. За выбранный период отсутствуют данные о начислениях или оплате труда. Система сообщает об отсутствии данных
- A2. Не удалось получить данные из iiko. Система отображает сообщение об ошибке
- A3. По отдельным сотрудникам отсутствуют данные об оплате труда.
Система отображает доступные данные и отдельно сообщает о неполноте информации
- A4. В выбранном периоде присутствуют дополнительные начисления (премии, надбавки, доплаты).
Система учитывает их в расчете ФОТ согласно правилам начисления заработной платы

### Постусловия

В истории диалога отображена общая сумма фонда оплаты труда за выбранную неделю или месяц с разбивкой по сотрудникам и указанием доли каждого сотрудника в общем ФОТ.

_Примечания. Уточнить у заказчика:_

- _Какие составляющие включать в ФОТ: оклады, почасовую оплату, премии, надбавки, доплаты и налоги?_
- _Использовать фактически начисленную или фактически выплаченную заработную плату?_
- _Учитывать ли отпускные, больничные и другие дополнительные выплаты?_

_Примечания. Уточнить у заказчика:_

- Учитывать только рабочие дни заведения или все календарные дни, включая выходные?
- Как учитывать ежемесячные расходы?

## UC-38. Расчет доли ФОТ в выручке заведения

| Поле        | Описание                                                                                                                                 |
|-------------|------------------------------------------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                                                       |
| Цель        | Определить долю ФОТ в общей выручке заведения за выбранный период                                                                        |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о выручке заведения и начислениях заработной платы сотрудникам за выбранный период |
| Триггер     | Пользователь выбирает запрос "Расчет доли ФОТ в выручке заведения"                                                                       |
| Итерация    | 1                                                                                                                                        |

### Основной сценарий

| № | Действие пользователя                          | Действие системы                                                                     |
|---|------------------------------------------------|--------------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Фонд оплаты труда"         | Отображает доступные запросы                                                         |
| 2 | Выбирает "Расчет доли ФОТ в выручке заведения" | Отображает варианты выбора периода                                                   |
| 3 | Выбирает период                                | Формирует запрос с указанным периодом                                                |
| 4 | -                                              | Получает из iiko данные о выручке заведения и фонде оплаты труда за выбранный период |
| 5 | -                                              | Рассчитывает общую сумму выручки и ФОТ за выбранный период                           |
| 6 | -                                              | Рассчитывает долю ФОТ в выручке                                                      |
| 7 | -                                              | Отображает общую выручку, сумму ФОТ и долю ФОТ в процентах за выбранный период       |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. За выбранный период отсутствуют данные о выручке или ФОТ. Система сообщает об отсутствии данных и указывает, каких именно показателей не хватает
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке
- A4. Выручка за выбранный период равна нулю. Система сообщает о невозможности расчета процентной доли ФОТ
- A5. Данные о ФОТ доступны не за весь выбранный период. Система предупреждает о неполноте данных и указывает период, за который выполнен расчет

### Постусловия

В истории диалога отображена информация об общей выручке заведения, 
сумме фонда оплаты труда и доле ФОТ в выручке в процентах за выбранный период.
