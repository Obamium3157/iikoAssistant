# Склад

## UC-12. Текущие остатки

| Поле        | Описание                                                                   |
|-------------|----------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                         |
| Цель        | Получить информацию о текущем остатке выбранного товара на складе          |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о складских остатках |
| Триггер     | Пользователь выбирает запрос "Текущие остатки"                             |
| Итерация    | 1                                                                          |

### Основной сценарий

| № | Действие пользователя         | Действие системы                                                 |
|---|-------------------------------|------------------------------------------------------------------|
| 1 | Выбирает категорию "Склад"    | Отображает доступные запросы                                     |
| 2 | Выбирает "Текущие остатки"    | Запрашивает наименование товара                                  |
| 3 | Указывает наименование товара | Ищет товар в справочнике iiko                                    |
| 4 | -                             | Получает информацию о текущих остатках выбранного товара из iiko |
| 5 | -                             | Определяет количество товара в наличии                           |
| 6 | -                             | Отображает текущий остаток товара с указанием единицы измерения  |

### Альтернативные сценарии

- A1. Пользователь указал неоднозначное наименование товара. Система предлагает выбрать товар из списка совпадений
- A2. Товар отсутствует в справочнике или не найден. Система сообщает об отсутствии товара
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

### Постусловия

В истории диалога отображен текущий остаток выбранного товара с указанием количества и единицы измерения.

## UC-13. Критически низкие остатки

| Поле        | Описание                                                                                                              |
| ----------- | --------------------------------------------------------------------------------------------------------------------- |
| Инициатор   | Владелец заведения                                                                                                    |
| Цель        | Выявить товары, остатки которых достигли критически низкого уровня или скоро закончатся                               |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о складских остатках и установленные минимальные уровни запасов |
| Триггер     | Пользователь выбирает запрос "Критически низкие остатки"                                                              |
| Итерация    | 1                                                                                                                     |

### Основной сценарий

| № | Действие пользователя                | Действие системы                                                                 |
|---|--------------------------------------|----------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Склад"           | Отображает доступные запросы                                                     |
| 2 | Выбирает "Критически низкие остатки" | Формирует запрос на получение товаров с критически низкими остатками             |
| 3 | -                                    | Получает данные о складских остатках из iiko                                     |
| 4 | -                                    | Получает установленные минимальные уровни запасов для товаров                    |
| 5 | -                                    | Сравнивает текущие остатки с минимальными уровнями                               |
| 6 | -                                    | Определяет товары, остатки которых достигли критического уровня                  |
| 7 | -                                    | Отображает список таких товаров с указанием текущего остатка и единицы измерения |

### Альтернативные сценарии

- A1. Все товары имеют достаточный запас. Система сообщает, что товаров с критически низкими остатками нет
- A2. Для товаров не установлены минимальные уровни запасов. Система сообщает о невозможности определить критически низкие остатки для таких товаров
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

### Постусловия

В истории диалога отображен список товаров с критически низкими остатками и указанием их текущего количества и единиц измерения.

_Примечание: необходимо согласовать с заказчиком критерии критически низкого остатка:
минимальный уровень запасов, прогнозируемое время до исчерпания или оба показателя._

количество поступившего и списанного товара с указанием единицы измерения.

## UC-16. Прогноз закупок

| Поле        | Описание                                                                                                     |
|-------------|--------------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                           |
| Цель        | Определить, на сколько дней хватит текущего запаса выбранного товара на основании данных о его расходе       |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о текущих складских остатках и истории расхода товаров |
| Триггер     | Пользователь выбирает запрос "Прогноз закупок"                                                               |
| Итерация    | 2                                                                                                            |

### Основной сценарий

| № | Действие пользователя         | Действие системы                                                                                        |
|---|-------------------------------|---------------------------------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Склад"    | Отображает доступные запросы                                                                            |
| 2 | Выбирает "Прогноз закупок"    | Запрашивает наименование товара                                                                         |
| 3 | Указывает наименование товара | Формирует запрос на получение данных о текущем остатке и расходе товара                                 |
| 4 | -                             | Получает данные о текущем остатке выбранного товара из iiko                                             |
| 5 | -                             | Получает исторические данные о расходе товара за выбранный период                                       |
| 6 | -                             | Рассчитывает среднесуточный расход товара                                                               |
| 7 | -                             | Определяет, на сколько дней хватит текущего запаса                                                      |
| 8 | -                             | Отображает текущий остаток, среднесуточный расход и прогнозируемое количество дней до исчерпания запаса |

### Альтернативные сценарии

- A1. По выбранному товару отсутствуют данные о расходе. Система сообщает о невозможности построить прогноз
- A2. Текущий остаток товара равен нулю. Система сообщает об отсутствии товара в наличии
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

### Постусловия

В истории диалога отображен прогнозируемый срок, на который хватит текущего запаса выбранного товара,
с указанием текущего остатка и среднесуточного расхода.

_Примечание: необходимо согласовать с заказчиком период истории расхода,
используемый для прогноза, а также правила учета сезонности и нерегулярного потребления._
