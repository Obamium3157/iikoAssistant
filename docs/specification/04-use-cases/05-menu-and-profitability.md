# Анализ меню и рентабельности

## UC-22. Популярные и непопулярные позиции

| Поле        | Описание                                                                                               |
|-------------|--------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                     |
| Цель        | Определить наиболее и наименее продаваемые товары в выбранной категории за определенный период времени |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о продажах и категориях товаров                  |
| Триггер     | Пользователь выбирает запрос "Популярные и непопулярные позиции"                                       |
| Итерация    | 1                                                                                                      |

### Основной сценарий

| № | Действие пользователя                             | Действие системы                                                                   |
|---|---------------------------------------------------|------------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Анализ меню и рентабельности" | Отображает доступные запросы                                                       |
| 2 | Выбирает "Популярные и непопулярные позиции"      | Отображает список категорий товаров                                                |
| 3 | Выбирает категорию товаров                        | Отображает варианты выбора периода                                                 |
| 4 | Выбирает период                                   | Формирует запрос с указанной категорией и периодом                                 |
| 5 | -                                                 | Получает данные о продажах из iiko                                                 |
| 6 | -                                                 | Группирует продажи по товарам выбранной категории и рассчитывает количество продаж |
| 7 | -                                                 | Определяет наиболее и наименее продаваемые позиции                                 |
| 8 | -                                                 | Отображает рейтинг товаров с указанием количества продаж за выбранный период       |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольный период. Система предлагает указать начальную и конечную даты
- A2. За выбранный период отсутствуют данные о продажах. Система сообщает об отсутствии данных
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

### Постусловия

В истории диалога отображен рейтинг наиболее и наименее продаваемых товаров выбранной категории 
за указанный период с указанием количества продаж каждой позиции.

_Примечание: необходимо уточнить у заказчика, популярность позиции определяется 
по количеству проданных единиц или по количеству заказов, в которых присутствует данная позиция._

## UC-24. Сравнение продаж

| Поле        | Описание                                                                                                  |
|-------------|-----------------------------------------------------------------------------------------------------------|
| Инициатор   | Владелец заведения                                                                                        |
| Цель        | Определить позиции меню, продажи которых выросли или снизились по сравнению с предыдущим периодом времени |
| Предусловия | Доступно подключение к iiko. В системе имеются данные о продажах по позициям меню за сравниваемые периоды |
| Триггер     | Пользователь выбирает запрос "Сравнение продаж"                                                           |
| Итерация    | 2                                                                                                         |

### Основной сценарий

| № | Действие пользователя                             | Действие системы                                                                                                      |
|---|---------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| 1 | Выбирает категорию "Анализ меню и рентабельности" | Отображает доступные запросы                                                                                          |
| 2 | Выбирает "Сравнение продаж"                       | Запрашивает первый период для сравнения                                                                               |
| 3 | Выбирает первый период                            | Запрашивает второй период для сравнения                                                                               |
| 4 | Выбирает второй период                            | Формирует запрос с указанными периодами                                                                               |
| 5 | -                                                 | Получает данные о продажах по позициям меню из iiko за оба периода                                                    |
| 6 | -                                                 | Рассчитывает количество продаж каждой позиции за каждый период и определяет изменение показателей                     |
| 7 | -                                                 | Определяет позиции с наибольшим ростом и снижением продаж                                                             |
| 8 | -                                                 | Отображает результаты сравнения с указанием позиций, количества продаж и динамики в абсолютных и процентных значениях |

### Альтернативные сценарии

- A1. Пользователь выбирает произвольные периоды. Система предлагает указать начальные и конечные даты для каждого периода
- A2. За один из выбранных периодов отсутствуют данные о продажах. Система сообщает об отсутствии данных
- A3. Не удалось получить данные из iiko. Система отображает сообщение об ошибке

### Постусловия

В истории диалога отображены результаты сравнения продаж по позициям меню за два выбранных периода 
с указанием товаров, продажи которых выросли или снизились, и величины изменения в абсолютных и процентных значениях.

_Примечание: необходимо согласовать с заказчиком, сравнивать ли количество проданных единиц, 
выручку или оба показателя. 
Также необходимо определить, должны ли сравниваемые периоды иметь одинаковую продолжительность._
